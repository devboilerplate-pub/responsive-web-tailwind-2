# 프로젝트 에셋(Assets) 현황

현재 프로젝트 내의 모든 이미지 및 영상 파일에 대한 검토 결과, **외부 링크(CDN, Web URL 등)를 통해 동적으로 불러오는 이미지/영상 리소스는 존재하지 않습니다.** 

모든 리소스 파일은 이미 다운로드되어 프로젝트 내부의 `images/` 폴더 내에 안전하게 관리(로컬 저장)되고 있으며, 각 소스 코드(`data.js`, `index.html` 등)에서는 상대 경로(예: `./images/recipe-1.jpg`)를 통해 올바르게 연결되어 있습니다.

## 로컬 저장소 에셋 목록 (`images/` 폴더)

총 13개의 이미지 파일이 포함되어 있습니다.

- `hero.jpg` (메인 히어로 섹션 배경 이미지)
- `recipe-1.jpg` ~ `recipe-12.jpg` (각 레시피 카드 및 모달용 썸네일 이미지)

> [!NOTE]
> 추가적인 외부 링크 에셋이 도입될 경우, 성능 및 안정성을 위해 현재와 같이 로컬 폴더로 다운로드하여 관리하는 것을 권장합니다.
