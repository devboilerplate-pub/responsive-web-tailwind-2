# Tailwind CSS를 적용하는 웹 사이트에서 중요하게 고려해야 하는 문제

Tailwind CSS를 CDN으로 불러오는 경우에 다음과 같은 문제점이 발생한다.
문제점: 이는 브라우저가 사이트를 열 때마다 방대한 Tailwind 스크립트를 다운로드하고, 사용자의 기기에서 실시간(Runtime)으로 CSS를 생성하게 만든다. 로딩 속도가 느려지고 성능에 악영향을 미친다.
해결책: Node.js 환경에서 Tailwind를 설치하여(PostCSS 등 활용) 프로젝트에서 실제로 사용한 클래스만 뽑아낸 가벼운 하나의 CSS 파일로 빌드하여 연결해야 한다.

### 프로젝트 적용 내용 (Tailwind CSS 빌드 마이그레이션)

위의 문제점을 해결하기 위해 본 프로젝트에서는 다음과 같이 빌드 환경을 구축하여 적용하였다.

1. **Node.js 패키지 초기화 및 모듈 설치**:
   - `npm init -y`를 통해 `package.json`을 생성하고, `@tailwindcss/cli` 및 `tailwindcss` 패키지를 설치했다.
2. **테마 설정 분리**:
   - 기존 `index.html`의 `<script>` 태그 내에 하드코딩 되어있던 사용자 정의 테마(`colors`, `fontFamily`, `aspectRatio`)를 전용 설정 파일인 `tailwind.config.js`로 분리하여 유지보수성을 높였다.
3. **CSS 빌드 파이프라인 구축**:
   - `css/input.css`에 Tailwind 지시어(`@tailwind` 및 `@config`)를 삽입하고, `package.json`에 `build:css`와 `watch:css` 스크립트를 추가하여 명령어로 손쉽게 CSS를 빌드할 수 있도록 설정했다.
4. **최적화된 CSS 연결**:
   - 브라우저 부하를 일으키던 `index.html` 내부의 CDN 링크를 제거하고, 빌드 과정을 거쳐 생성된 최적화된 `css/output.css` 파일을 연결했다.
