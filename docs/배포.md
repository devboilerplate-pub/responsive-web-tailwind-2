# Vercel 배포 분석 및 설정 가이드

현재 프로젝트 상태를 분석한 결과, **Vercel 플랫폼에 배포하는 데 아무런 문제가 없는 완전한 상태**입니다.
이 프로젝트는 HTML, CSS, Vanilla JS로 구성된 정적(Static) 웹사이트이며, 다음과 같은 설정들이 배포에 최적화되도록 구성되어 있습니다.

## 1. 빌드 환경 자동화 (Vercel 호환성 완비)
Vercel은 기본적으로 Node.js 기반 프로젝트의 빌드 스크립트를 감지하여 클라우드 상에서 컴파일을 수행합니다.
이를 위해 `package.json`에 `build` 스크립트를 추가해 두었습니다.

- **추가된 내용**: `"build": "npm run build:css"`
- **효과**: 개발자가 로컬에서 매번 CSS를 빌드한 뒤 `output.css`를 깃허브에 올리지 않더라도, Vercel이 깃허브 변경사항을 감지하면 자동으로 `build` 명령어를 실행하여 최신 상태의 Tailwind CSS 결과물을 만들어낸 뒤 서빙하게 됩니다.

## 2. Vercel 라우팅 최적화 (`vercel.json`)
정적 웹사이트의 사용자 경험(UX)과 SEO를 높이기 위해 프로젝트 루트에 `vercel.json` 파일을 추가해 두었습니다.

```json
{
  "cleanUrls": true,
  "trailingSlash": false
}
```
- `cleanUrls`: `.html` 확장자를 주소창에서 숨겨주어 깔끔한 URL(`.../about` 형식)을 제공합니다. (추후 서브 페이지 추가 시 유용)
- `trailingSlash`: URL 끝에 붙는 슬래시(`/`)를 제거하도록 강제하여 중복된 URL 문제(SEO 악영향)를 방지합니다.

## 배포 방법 (How to deploy)
현재의 설정대로라면 아래 두 가지 방법 중 하나로 즉시 배포가 가능합니다.

1. **GitHub 연동 배포 (권장)**:
   - 본 프로젝트를 GitHub 리포지토리에 푸시(`push`)합니다.
   - Vercel 대시보드(vercel.com)에 로그인 후 **[Add New Project]**를 클릭합니다.
   - 해당 리포지토리를 `Import`하면, Vercel이 자동으로 `package.json`의 `build` 명령어를 감지합니다.
   - 추가 설정 없이 **[Deploy]** 버튼을 누르기만 하면 수십 초 내에 성공적으로 배포됩니다.

2. **Vercel CLI를 통한 배포**:
   - 로컬 터미널에서 `npm i -g vercel`로 CLI 도구를 설치합니다.
   - 터미널에서 `vercel` 명령어를 입력하고 화면의 지시를 따르면 즉시 배포됩니다.
